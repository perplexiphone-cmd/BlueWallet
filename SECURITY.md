# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities.

Report security concerns privately through GitHub private vulnerability reporting if it is available for this repository, or contact `bluewallet at bluewallet dot io`. Include the affected file, branch or commit, reproduction steps, device/platform details, and the expected impact.

Do not include secrets, wallet seed phrases, private keys, xpubs tied to real funds, API tokens, Lightning credentials, device passcodes, screenshots containing balances or addresses you want private, or production logs in reports.

## Wallet and Device Safety

Never commit or share real wallet backups, seed phrases, signing keys, device credentials, simulator keychains, provisioning profiles, or production service tokens. Use test wallets and disposable credentials for development and reproduction.

## Supported Versions

Security fixes are handled on the default branch. Keep devices and deployments updated, and rotate any exposed credentials immediately.
